❓ Before You Contact Us

Many common questions are answered in our FAQ section.

Common Issues & Solutions

"I can't extract subtitles from a video"

  • Make sure the video has captions available (check if CC icon appears on YouTube)
  • Try refreshing the page and extracting again
  • Some videos have captions disabled by the creator

"The transcript is inaccurate"

  • We retrieve existing subtitles from YouTube; we don't create them
  • Auto-generated captions can have errors
  • Try selecting manually-created subtitles if available

"The website is slow"

  • Try clearing your browser cache
  • Disable browser extensions temporarily
  • Try a different browser

"Export isn't working"

  • Make sure you've successfully extracted a transcript first
  • Check that your browser allows downloads
  • Try a different export format

🐛 Report a Bug

Found something broken? Help us fix it by providing:

  1. What happened? (Describe the issue)
  2. What did you expect? (What should have happened)
  3. Steps to reproduce (How can we recreate the issue)
  4. Browser & device (Chrome on Windows, Safari on iPhone, etc.)
  5. Screenshot (If applicable)

Send bug reports to: support@ytscript.com with "Bug Report" in the subject line.
