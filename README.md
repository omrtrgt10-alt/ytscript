# YTScript - YouTube Subtitle Extractor

Free online tool to extract subtitles from YouTube videos.

## Features
- Extract subtitles instantly
- Multiple formats (TXT, SRT, VTT, JSON, PDF, DOCX)
- No signup required
- Dark/Light mode

## Tech Stack
- Python/Flask backend
- Vanilla JS frontend
- youtube-transcript-api
